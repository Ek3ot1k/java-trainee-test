# Контекст фрагмента

Это изолированный фрагмент Pull Request. Предполагается, что приложение использует Spring Boot 3, Spring Data JPA и PostgreSQL, а таблицы уже созданы миграциями.

Требование к PR: создать заказ по списку товаров, использовать актуальные цены из каталога, уменьшить остатки атомарно и вернуть сохранённый заказ. Если хотя бы одну позицию нельзя обработать, заказ не должен создаваться.

Фрагмент предназначен для чтения и review; отдельный build-файл намеренно не приложен.
