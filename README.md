# Fox Market — тестовое задание для Java Trainee / Junior

В этой папке находится тестовое задание на позицию Java Trainee / Junior Java Developer. Оно состоит из двух частей:

1. Реализовать небольшой сервис создания и чтения заказа.
2. Провести review небольшого фрагмента кода из Pull Request.

Мы не ожидаем идеального production-ready решения. Нам важнее увидеть, как вы понимаете задачу, принимаете решения, работаете с ошибками и объясняете свой код.

Срок выполнения — **1–2 календарных дня** с момента получения задания, включая review. Планируйте работу самостоятельно внутри этого срока. Если закончить всё не удалось, отправьте рабочую часть и честно опишите дальнейший план — это полезнее спешно дописанного решения.

В идеале результатом должен стать **полноценный запускаемый проект**: приложение поднимается по инструкции, база создаётся миграциями, API можно продемонстрировать, а тесты — запустить. На следующем этапе мы попросим вас пошарить экран, запустить решение и рассказать о нём: показать структуру, провести один запрос через код до базы и объяснить принятые решения.

## С чего начать

1. Прочитайте [TASK.md](TASK.md).
2. Прочитайте [RULES.md](RULES.md).
3. Решите, использовать ли минимальный проект из `starter/` или создать свой.
4. Выполните основную задачу и обязательные тесты.
5. Заполните свой README по требованиям из [SUBMISSION.md](SUBMISSION.md).
6. Выполните [CODE_REVIEW.md](CODE_REVIEW.md).

Можно пользоваться Google, Stack Overflow, IDE autocomplete и официальной документацией Java, Spring и PostgreSQL. Ограничения на использование генеративного AI описаны в `RULES.md`.

## Для команды Fox Market

> **Не отправляйте кандидату каталог `internal/`.** Он содержит rubric, answer key и материалы интервью. Перед выдачей задания подготовьте копию без `internal/` или проверьте содержимое архива вручную.

Кандидату передаются корневые документы, `code-review/` и, при необходимости, `starter/`.
