# Что отправить

Пришлите ссылку на Git-репозиторий или архив, в котором сохранена история Git.

В решении должны быть:

- исходный код;
- миграции базы данных;
- минимум три обязательных автоматических теста;
- инструкция запуска;
- результат Code Review в отдельном Markdown-файле;
- ваш README.

В идеале это должен быть полноценный запускаемый проект. Перед отправкой проверьте весь путь по собственной инструкции: запуск PostgreSQL, применение Liquibase-миграций, старт приложения, создание и чтение заказа, запуск автоматических тестов.

В README своими словами кратко опишите:

- как запустить приложение и тесты;
- структуру решения;
- основные архитектурные решения;
- важные trade-offs и предположения;
- как обработаны повторяющиеся `productId`;
- что считаете слабым местом решения;
- что улучшили бы ещё за несколько часов;
- что не успели сделать и как собирались это закончить.

Большой или красиво оформленный README не нужен. Нам интересен ход инженерной мысли. Убедитесь, что проект можно запустить по вашей инструкции на чистой машине с указанными prerequisites.

На техническом интервью мы попросим вас пошарить экран, запустить проект и провести короткую демонстрацию. Будьте готовы показать структуру решения, выполнить API-запрос, разобрать путь данных до БД и объяснить один из тестов. Специальную презентацию готовить не нужно.
